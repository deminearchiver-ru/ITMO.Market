# ITMO.Market Dashboard

This workspace will contain the ITMO.Market dashboard in the form a of web app. We are still deciding whether to use Flutter Web or classic Web Technologies (including frameworks) for this part.

Currently, possible technologies for building this part of ITMO.Market include:

- Flutter Web

- Plain HTML, CSS & JavaScript (TypeScript).

- Solid 2.0 - a well-tested, battle-ready release of the innovative reactive web framework, Solid.js.

- React - a classic reactive framework, the most common choice for building web frontends.
